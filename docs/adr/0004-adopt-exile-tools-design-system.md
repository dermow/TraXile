# Adopt the exile-tools.com design system instead of Fluent

TraXile.Next follows the complete design system of exile-tools.com (colors, the fonts Orbitron / Familjen Grotesk / Instrument Sans, 2/4 px corners, surfaces instead of hairlines, dark and light theme) rather than the default Windows 11 Fluent look with Mica, so the app and the website that presents it look like one product. WPF-UI stays as the control library but is restyled; Mica is dropped because it tints the warm background with the desktop wallpaper. We adopt a fixed, dated snapshot of the website tokens documented in `docs/design.md` and sync deliberately via a ticket, instead of pulling the CSS at build time, because the source site (`dev.`) is still changing. Coral is reserved for UI accents; activity type colors are derived from the website's data colors.
